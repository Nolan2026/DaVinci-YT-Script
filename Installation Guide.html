YouTube → DaVinci Resolve

Complete Installation Guide — Follow each step in order

Windows macOS Linux
✨ What This Script Does
  • ● Paste any YouTube URL inside DaVinci Resolve and download the video instantly
  • ● Choose resolution: Best · 2160p · 1440p · 1080p · 720p · 480p · 360p
  • ● Auto-imports the downloaded clip into your Media Pool
  • ● Optionally appends the clip to your current timeline
  • ● Live progress bar — window never freezes while downloading
  • ● Remembers your save folder between sessions
📋 Requirements
Tool Required? Purpose
Python 3.8+ ✅ Required Runs the script
yt-dlp ✅ Required Downloads videos from YouTube
ffmpeg ⚠️ Recommended Merges video + audio for best quality (1080p+)
Node.js ⚠️ Optional Fixes YouTube 403 / n-challenge download errors
⚡ Option A — One-Click Install (Easiest)
  • 1 Download both files to the same folder on your PC:
       installationFile.bat  &  YouTubeDownloader.py
  • 2 Right-click installationFile.bat → Run as administrator
  • 3 The installer will automatically install everything and copy the script to Resolve
  • 4 Open DaVinci Resolve → Workspace → Scripts → Utility → YouTubeDownloader
⚠️ You must right-click and choose Run as administrator — otherwise the installer cannot write to system folders.
🛠️ Option B — Manual Install (Step by Step)
1
Check / Install Python

Download from python.org/downloads — tick "Add Python to PATH" during install.

✅ Verify
python --version
2
Install yt-dlp
🪟 Windows / 🍎 macOS / 🐧 Linux
pip install -U yt-dlp
✅ Verify
yt-dlp --version
3
Install ffmpeg (Recommended)
🪟 Windows — winget (easiest)
winget install Gyan.FFmpeg
🍎 macOS — Homebrew
brew install ffmpeg
🐧 Ubuntu / Debian
sudo apt update && sudo apt install ffmpeg -y
✅ Verify
ffmpeg -version
4
Install Node.js (Optional — fixes 403 errors)
🪟 Windows — winget
winget install OpenJS.NodeJS
🍎 macOS — Homebrew
brew install node
🐧 Ubuntu / Debian
sudo apt install nodejs npm -y
✅ Verify
node --version
5
Copy Script to DaVinci Resolve

Copy YouTubeDownloader.py to the Resolve Utility folder for your OS:

🪟 Windows — PowerShell
# Create folder New-Item -ItemType Directory -Force -Path "$env:APPDATA\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility" # Copy script Copy-Item "YouTubeDownloader.py" "$env:APPDATA\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\"
🍎 macOS — Terminal
mkdir -p "/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility" cp YouTubeDownloader.py "/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/"
🐧 Linux — Terminal
mkdir -p ~/.local/share/DaVinciResolve/Fusion/Scripts/Utility cp YouTubeDownloader.py ~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/
📁 Resolve Script Folder Paths
🪟 Windows
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility
🍎 macOS
/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility
🐧 Linux
~/.local/share/DaVinciResolve/Fusion/Scripts/Utility
🚀 How to Use Inside DaVinci Resolve
  • 1 Open DaVinci Resolve with a project open
  • 2 Click Workspace in the top menu bar
  • 3 Go to Scripts → Utility → YouTubeDownloader
  • 4 Paste your YouTube URL in the URL box
  • 5 Choose a resolution and click Download & Add
  • 6 The video downloads and is added to your Media Pool automatically 🎉
🛠️ Troubleshooting
Problem Fix
yt-dlp: command not found Run pip install -U yt-dlp and make sure pip is on PATH
Video downloads but no audio Install ffmpeg (Step 3)
403 / n-challenge error Install Node.js (Step 4)
Script not in Workspace → Scripts Check YouTubeDownloader.py is in the correct Utility folder
Clip not added to Media Pool Make sure a project is open in Resolve before downloading
429 / Bot-check error Export YouTube cookies with "Get cookies.txt LOCALLY" extension and load in the Cookies field
